# PennyWise

A responsive, client-side expense tracker built with HTML, CSS, and vanilla JavaScript.

## Run it

Open `index.html` in a modern browser. No build step or package installation is required. If you prefer, serve the folder with any static web server.

## Pages and features

- **Overview** — monthly income and spending totals, cash-flow chart, budget progress, and recent activity.
- **Transactions** — searchable and filterable activity, CSV export, and a validated add-transaction form.
- **Budgets** — category limits, progress indicators, and create, update, and remove actions.
- Responsive navigation and layouts for mobile, tablet, and desktop.
- Demo data and changes are saved in browser local storage. This static demo does not connect to a financial institution or remote API.
